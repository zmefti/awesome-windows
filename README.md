# Awesome Windows — Curated Tools & Apps

A modern, fast, and beautifully curated list of the best software and developer tools for Windows 10/11, presented as a single-file, interactive web app with instant filtering and search.

## ✨ Features

- **Curated Selection**: Hand-picked applications across multiple categories (Development, Productivity, System Utilities, Security, Media, and more).
- **Instant Search & Filtering**: Real-time filtering by app name, description, or category as you type.
- **Quick Badges**: Easily identify **⭐ Personal Favorites**, **🟢 Open Source** projects, and **💰 Paid** software at a glance.
- **Single-File Architecture**: Built entirely with plain HTML, CSS (using modern custom properties and Google Fonts like *Syne* and *DM Mono*), and vanilla JavaScript. No complex build tools or frameworks required.
- **Responsive Layout**: Designed for a seamless experience on both desktop and mobile devices.
